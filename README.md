# OUTMAX SALE

Адаптивный прототип интернет-магазина OUTMAX с накопительной скидкой до 50%. Проект работает как статический сайт без сборки и опубликован через GitHub Pages.

[Открыть сайт](https://divangames.github.io/out_saller/)

## Возможности

- каталог кроссовок, одежды и аксессуаров с фильтрами;
- индивидуальные описания, характеристики и фотогалереи товаров;
- мужские и женские таблицы размеров;
- отображение длины стопы и остатка выбранного размера;
- корзина с автоматическим расчётом скидки;
- оформление заявки с проверкой формы и выбором ПВЗ;
- локальные подсказки по 1102 городам России;
- адаптивный интерфейс для компьютеров и мобильных устройств;
- сохранение корзины в `localStorage`;
- hash-маршрутизация, совместимая с GitHub Pages.

## Локальный запуск

На Windows запустите:

```text
START.bat
```

и выберите пункт `1. Запуск`.

Либо запустите любой статический HTTP-сервер из корня проекта:

```powershell
python -m http.server 4173
```

После этого откройте [http://127.0.0.1:4173/#home](http://127.0.0.1:4173/#home).

Открывать `index.html` напрямую через `file://` не рекомендуется: браузер ограничивает загрузку локальных файлов и часть функций может не работать.

| `index.html` | Точка входа и подключение стилей и данных |

| `city-suggestions.js` | Поиск и выбор города в форме оформления |
| `scripts/` | Скрипты обновления товарных данных |
| `images/`, `assets/figma/` | Изображения и SVG-интерфейса |
| `DEPLOYMENT.md` | Контракт переноса интерфейса и сведения о маршрутах |

## Обновление данных

Галереи из `https://outmaxshop.com/yml/all.yml`:

```powershell
pwsh -File scripts/sync-product-photos.ps1
```

Остатки из `https://outmaxshop.ru/yml/all_yandex.yml`:

```powershell
pwsh -File scripts/sync-product-stock.ps1
```

Описания и расширенные данные из заранее скачанной выгрузки:

```powershell
pwsh -File scripts/sync-product-details.ps1 -FeedPath artifacts/all_yandex.yml
```

Скрипты обновляют статические снимки данных. Перед публикацией рекомендуется повторно получить актуальные остатки.

## Публикация

Push в ветку `main` автоматически запускает workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml) и публикует содержимое репозитория на GitHub Pages.

На Windows команды для коммита, push и ручного запуска публикации также доступны через `START.bat`.

## Важные ограничения

- Это статический прототип: актуальность цен и остатков зависит от последнего обновления YML-снимков.
- Расчёт доставки и перечень ПВЗ пока заданы демонстрационными данными и не подключены к API СДЭК.
- Данные Telegram-бота хранятся только локально в `TG BOT.txt`; файл исключён из Git. Для production токен необходимо перенести на сервер и не выдавать браузеру.
- Пользовательский ввод города не отправляется внешним сервисам: подсказки работают по локальному справочнику.
